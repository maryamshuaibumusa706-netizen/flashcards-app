# flashcards-app#
🧠 Neon Flashcards

A simple study app to create, flip, and manage flashcards.

**Live Demo:** [Add your Netlify link here]

### Features
- Click to flip cards (question → answer)
- Add new cards via form
- Delete current card and go back to previous
- Prev / Next navigation with card counter
- Input validation for empty questions/answers

### Tech Used
- HTML, CSS, JavaScript
- TypeScript concepts: `FlashCard` interface, typed collections, custom `InvalidUserInputError`

### What I Learned
- Managing state with an array + current index
- DOM manipulation and event handling
- Handling edge cases (empty deck, deleting last card)
